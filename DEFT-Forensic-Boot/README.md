# DEFT Zero Forensic Boot Environment

Practical digital forensics lab focused on creating and validating a bootable DEFT Zero forensic environment.

## Objective

The objective was to create bootable forensic media and validate the forensic environment while maintaining a non-destructive approach to evidence examination.

## Tools & Environment

- DEFT Zero
- Balena Etcher
- USB Flash Drive
- BIOS/UEFI boot environment

## Activities

- Prepared the DEFT Zero ISO image.
- Attempted creation of bootable optical media.
- Created a bootable USB drive using Balena Etcher.
- Successfully booted the target system from the USB.
- Verified the DEFT Zero live environment and available forensic tools.
- Booted the environment in UEFI mode.

## Forensic Concepts

- Live forensic environment
- Bootable forensic media
- Read-only evidence handling
- Non-destructive examination
- BIOS/UEFI boot process

## Skills Demonstrated

- Forensic environment preparation
- Bootable media creation
- UEFI boot configuration
- Evidence-preservation principles
- DEFT Zero forensic environment
