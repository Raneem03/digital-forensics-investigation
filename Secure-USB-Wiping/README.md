# Secure USB Data Wiping

Practical digital forensics lab focused on securely wiping a USB storage device before forensic imaging.

## Objective

The objective was to securely erase data from a USB flash drive so that previously stored information could not be recovered through standard forensic recovery techniques.

## Environment

- Operating System: Windows 10
- Storage Device: 8 GB USB Flash Drive
- File System: NTFS
- Administrator privileges

## Tool

- Directory Snoop

## Activities

- Identified the file system of the USB storage device.
- Deleted existing files from the USB drive.
- Used Directory Snoop with administrator privileges.
- Selected the appropriate NTFS module.
- Performed a secure wipe using multiple passes.
- Verified completion of the wiping process.

## Forensic Concepts

- Secure data destruction
- File system artifacts
- Data recoverability
- Forensic preparation of storage media
- NIST SP 800-88

## Skills Demonstrated

- Secure storage media wiping
- Windows file-system handling
- Digital forensic preparation
- Use of forensic data-destruction tools
