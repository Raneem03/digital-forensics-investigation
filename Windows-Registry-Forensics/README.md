# Windows Registry Forensics

Practical digital forensics work focused on acquiring and examining Windows Registry artifacts using DART, FTK Imager, and AccessData Registry Viewer.

## Scope

This work covers four related forensic activities:

### 1. Registry Acquisition — DART & FTK Imager
- Live Windows forensic acquisition
- Exporting Windows Registry hives
- SAM, SYSTEM, SOFTWARE, SECURITY, DEFAULT
- NTUSER.DAT
- FTK Imager within DART

### 2. SAM Hive Analysis
- Examining the Security Accounts Manager (SAM) hive
- User account identification
- Security Identifiers (SIDs)
- Account status and metadata
- Logon-related information
- AccessData Registry Viewer

### 3. SYSTEM Hive Examination
- Examination of the Windows SYSTEM Registry hive
- Analysis of system-level Registry information
- Correlation with other Registry artifacts

### 4. NTUSER.DAT Analysis
- User-specific Registry analysis
- User account identifiers and GUIDs
- MRU artifacts
- Application and system usage artifacts
- User profile information
- Keyword-based Registry searches

## Tools

- AccessData Registry Viewer
